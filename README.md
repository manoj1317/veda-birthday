# Veda Birthday ♡

A private romantic birthday microsite for Veda, born 08 October 2001.

## Current version

The site has a password entrance, romantic/cinematic styling, a birthday letter, floating hearts, memory cards, a photo area, and a final birthday message.

## Important

The password gate is client-side only. Keep this repository private. If the site is later hosted publicly, use server-side authentication/password protection rather than relying on JavaScript for real security.
